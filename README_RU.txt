BLOCK WORLD 2D — Android-проект

Это базовая мобильная версия игры с сенсорным управлением, созданная как Android WebView-проект.

Чтобы собрать APK:
1. Установите Android Studio на ПК.
2. Откройте папку MC2D_Android.
3. Дождитесь Gradle Sync. Установите SDK 35 и Android Gradle Plugin, если потребуется.
4. Build -> Build APK(s).
5. APK будет в app/build/outputs/apk/debug/app-debug.apk.

На телефоне: кнопки влево/вправо, прыжок, кнопка размещения блока; нажимайте на блоки мира, чтобы добывать.

Пока это независимый прототип, не исходная Windows-игра. Архив Windows-версии не распакован в этом проекте.

Сборка APK через GitHub Actions (без Android Studio):
1. Создайте на GitHub новый репозиторий и загрузите туда содержимое этой папки.
2. Откройте вкладку Actions и выберите workflow Build Android APK.
3. Нажмите Run workflow (если запуск вручную доступен).
4. После успешной сборки откройте завершённый запуск, раздел Artifacts и скачайте BlockWorld2D-debug-apk.
5. Распакуйте архив artifact и установите APK на Android (разрешите установку из этого источника при необходимости).
